نسخهٔ وب برنامهٔ «چاپ لیست کلاسی».

## اجرا
پس از فعال شدن GitHub Pages، برنامه از نشانی زیر در دسترس خواهد بود:

https://mostafa-modaberi.github.io/webApps/

## ویژگی‌ها
- رابط فارسی و راست‌چین
- چاپ و خروجی مناسب برگهٔ A4
- ذخیره‌سازی داده‌ها در مرورگر با `localStorage`
- اجرا به‌صورت یک فایل HTML مستقل، بدون نیاز به نصب یا سرور اختصاصی

## انتشار
با هر بار push به شاخهٔ `main`، گردش‌کار GitHub Actions فایل‌های مخزن را روی GitHub Pages منتشر می‌کند.
